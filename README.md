# Aplicativo Confesional ICEPI v2.3 FINAL

Versión final para presentación institucional.

## Incluye
- Pantalla inicial con declaración confesional.
- Dashboard con cuatro módulos.
- Confesión de Londres de 1689 con buscador, capítulos, párrafos, superíndices interactivos y panel de referencias bíblicas.
- Credos históricos con texto centrado y reemplazo de “católica/católico” por “universal”.
- Historias ampliadas de los credos en texto narrativo.
- Historia ampliada de la Confesión.
- Módulo de importancia de credos y confesiones.
- Familia ICEPI con directorio editable.

## Uso
Descomprime el ZIP completo y abre `index.html` en el navegador.
